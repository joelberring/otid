# O-Tid

## Aktuell lokal demo

Den reproducerbara, isolerade syntetiska demon är den aktuella vägen för att
prova systemet. Följ [demoanvisningen](docs/demo-provisioning.md): skapa en ny
`otid_demo_`-databas, migrera den och kör den befintliga `demo:provision`-CLI:n.
Det privata manifestet innehåller bland annat en kortlivad `MANAGE_RACE`
credential för den gemensamma adminvyn `/admin/{raceId}/manage`; öppna
publikresultatet på `/results/{raceId}` utan inloggning. Inga credentials eller
privata sökvägar hör hemma i README, URL:er eller loggar.

Den äldre Docker-/`db:seed`-starten med fasta race-id:n är **legacy** och ska
inte användas för att bedöma aktuell version.

Första körbara vertikala tävlingskärnan för individuell orientering: skapa
tävling, importera IOF XML 3.0, simulera en avläsning, lagra resultatrevision och
visa offentliga resultat.

Efter TASK 001 finns även ett avgränsat transport-/capturefundament. Det listar
serieportar, bevarar råa bytes privat och replayar en verifierad capture utan att
tolka SPORTident-protokoll.

## Lokal start med Docker (legacy)

```bash
cp .env.example .env
docker compose up -d postgres minio minio-init
pnpm install
pnpm db:migrate
pnpm db:seed
pnpm dev
```

Seedloppet finns på
`/admin/10000000-0000-4000-8000-000000000002`.

Webbsimulatorn är avstängd som standard. För uttrycklig lokal utveckling krävs
`O_TID_SIMULATOR_MODE=loopback-development`, canonical
`O_TID_PUBLIC_ORIGIN=http://127.0.0.1:3000` och en devserver bunden till
loopback. Produktion tillåter aldrig simulatorn, oavsett modevariabel.

## Rå transport och capture

```bash
pnpm si:ports
pnpm si:capture --port /dev/cu.example --baud 38400 --out /säker/privat/katalog
pnpm si:replay fixtures/sportident/synthetic-transport-session/session.json
```

`si:ports` öppnar eller proberar inte en port. `si:capture` kräver explicita
port- och baudvärden och avvisar normalt output inne i repositoryt. Kommandona
bevisar inte SPORTident-stöd; riktig station, parser och kortavkodning återstår.

`DATABASE_URL` krävs för drift/migration. `TEST_DATABASE_URL` ska peka på en
separat PostgreSQL/PostGIS-databas för integrationstester. Projektet använder
inte SQLite som serverersättning.

TASK300:s `manual_class_create_request` är en oföränderlig requestjournal.
En full PostgreSQL-backup och återställning måste omfatta den tillsammans med
klass, bana, banversion, administratörscredential och audit. Vid återgång
stängs skrivvägen; en befolkad journal raderas inte utan rättas framåt eller
återställs ur en verifierad full backup.

TASK301:s `manual_class_name_change_request` är också en oföränderlig
requestjournal. Full backup/restore måste bevara den med klassens namn,
banversionsreferens, tävlingens snapshotversion, administratörscredential och
audit. Vid återgång stängs namnbytesvägen; journalen raderas inte separat.

Tävlingsskapande, tävlingsöversikt, pairing-, IOF-import-, klass-, resultat-,
finaliserings- och juryadministration kräver
`O_TID_PUBLIC_ORIGIN` som en exakt canonical origin. Produktion kräver HTTPS;
explicit HTTP till `localhost`, `127.0.0.1` eller `[::1]` är endast
utvecklingspolicy. Behörigheterna är separata och racebundna. En betrodd
operatör kan bootstrapas och spärras med:

```bash
pnpm pairing:admin:access:issue -- --race-id <uuid> --label <text> --expires-at <ISO>
pnpm pairing:admin:access:revoke -- --credential-id <uuid> --reason <text>
pnpm iof:import:access:issue -- --race-id <uuid> --label <text> --expires-at <ISO>
pnpm iof:import:access:revoke -- --credential-id <uuid> --reason <text>
pnpm entry:class:access:issue -- --race-id <uuid> --label <text> --expires-at <ISO>
pnpm entry:class:access:revoke -- --credential-id <uuid> --reason <text>
pnpm result:recalculation:access:issue -- --race-id <uuid> --label <text> --expires-at <ISO>
pnpm result:recalculation:access:revoke -- --credential-id <uuid> --reason <text>
pnpm result:approval:access:issue -- --race-id <uuid> --label <text> --expires-at <ISO>
pnpm result:approval:access:revoke -- --credential-id <uuid> --reason <text>
pnpm result:approval:withdrawal:access:issue -- --race-id <uuid> --label <text> --expires-at <ISO>
pnpm result:approval:withdrawal:access:revoke -- --credential-id <uuid> --reason <text>
pnpm race:overview:access:issue -- --race-id <uuid> --label <text> --expires-at <ISO>
pnpm race:overview:access:revoke -- --credential-id <uuid> --reason <text>
pnpm event:create:access:issue -- --label <text> --expires-at <ISO>
pnpm event:create:access:revoke -- --credential-id <uuid> --reason <text>
```

Den utskrivna accesscredentialen visas endast vid utfärdandet och ska hanteras
som en hemlighet. Eventskapandets `CREATE_EVENT`-credential är avsiktligt
icke-racebunden eftersom loppet ännu inte finns, men ger ingen rätt till något
befintligt eller nyskapat lopp. Övriga credentials är fortsatt racebundna.

## Medveten avgränsning

Simulatorpayload och transportfixturen är syntetiska och är inte
SPORTident-protokoll eller riktig USB.
Ingen Eventor-, GPS-, karttile-, stafett-, betalnings- eller generell
arrangörsautentisering ingår. Tävlingsskapande, de racebundna pairing-,
IOF-import-, klassändrings- och explicita omräkningsmutationerna samt den
PII-fria tävlingsöversikten har separata produktionsautentiserade gränser.
`/admin/{raceId}/simulator` är en fail-closed, loopbackbunden utvecklingsyta och
svarar 404 i produktion. Dess syntetiska kontrakt bevisar inte hårdvarustöd.
