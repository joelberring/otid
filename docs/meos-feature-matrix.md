# MeOS-funktionsmatris för O-Tid

Inventerad 2026-09-19; kontorader uppdaterade 2026-09-23. Produktmål: motsvarande användarnytta och information,
med självständig implementation och ett enklare sammanhängande arbetsflöde.
Detta är inte ett påstående om uppnådd paritet.

Aktuell ordning finns i [produktmålplanen](product-goal-roadmap-2026-09-23.md);
äldre etappnamn hänvisar till den [historiska genomförandeplanen](project-review-and-plan-2026-09-19.md).
Testfallskolumnen anger acceptans, inte att provet har körts i denna genomgång.
MeOS-källorna och deras begränsningar finns i
[researchnoteringen](research/meos-product-reference-2026-09-19.md).
Handbokens ordning och O-Tids aktuella navigationslucka granskas separat i
[arbetsflödesjämförelsen](research/meos-guide-workflow-2026-09-23.md);
funktionsförekomst och ett begripligt användarflöde är olika acceptansbevis.
